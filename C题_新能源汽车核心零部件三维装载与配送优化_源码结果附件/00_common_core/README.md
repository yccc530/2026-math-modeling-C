# 00_common_core 公共核心模块

本目录保存四个问题共同使用的基础代码和运行脚本。

## 子目录说明

- `code/`：公共数据配置、几何计算、三维装箱启发式、路径成本、候选车次优化、可视化与验证依赖模块。
- `run/`：完整运行、第二阶段优化、报告生成、审计与依赖清单等流程控制脚本。

## 设计原则

公共模块只保存跨问题复用的能力，分题求解器保存在各自问题目录中。这样可以避免重复代码，同时便于评阅者从单个问题入口追踪到公共计算函数。

## 运行说明

建议从项目根目录统一运行：

```bash
python run_project.py --check-imports
python run_project.py
```

若直接调用本目录下脚本，仍应保持当前工作目录为项目根目录，以确保输出路径和结果同步逻辑一致。
