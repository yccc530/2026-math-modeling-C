# 00_common_core 公共核心模块

本目录保存四个问题共同调用的基础代码与流程脚本。公共模块集中管理车辆、货物、几何约束、装箱逻辑、路径成本、候选车次优化、可视化和审计流程，避免各问题重复实现相同功能。

## 一、子目录说明

- `code/`：公共算法与数据模块。
- `run/`：完整运行、第二阶段优化、报告生成和审计脚本。

## 二、`code/` 主要文件

- `data_config.py`：定义车辆、货物、路线、装载结果等数据结构，固化题目给定数据，并生成问题三模拟数据。
- `geometry.py`：提供三维长方体几何、重叠判断、支撑面积、重心和投影面积等基础计算函数。
- `packing.py`：实现极点/角点三维装箱启发式、多排序策略、多姿态枚举和局部修复逻辑。
- `routing.py`：实现路线枚举、距离计算、运输成本计算、站点聚类和路线局部调整。
- `optimizer.py`：实现候选车次生成、集合覆盖选择、贪心回退和局部替换。
- `visualization.py`：生成三维装载图、车辆利用率图、策略对比图和敏感性分析图。

## 三、`run/` 主要文件

- `main.py`：一键运行问题一至问题四的主流程。
- `run_second_stage_optimization.py`：第二阶段优化入口，用于记录优化仪表盘、上下界 gap 和最终审计材料。
- `report_generator.py`：根据结果表和验证报告生成技术报告草稿。
- `audit.py`：检查数据一致性、约束完整性、结果可信性和论文风险。
- `requirements.txt`：项目运行依赖清单。

## 四、调用方式

公共模块通常不单独运行，而由根目录 `run_project.py` 或各问题求解器调用。请在项目根目录执行：

```bash
python run_project.py --check-imports
python run_project.py
```

若需直接调用 `run/` 中脚本，也应保持当前工作目录为项目根目录，以保证输入输出路径一致。
